P5 hardening: FW01 IDS-feed heartbeat (2026-10-28)

Before: FW01 (role "ids") sent no heartbeat, so a dead Suricata or a dead FW01 syslog
feed was not observable (THREAT_MODEL "Forged sensor lines" row, PROJECT_STATUS gap 5).

Change: FW01's watchdog (cron, every 30 s) logs one line under the "suricata" program
tag (OPNsense forwards only listed programs; arbitrary tags cannot be selected) with
event_type "afw_heartbeat", ONLY while `pgrep -x suricata` succeeds. The controller
classifies that event type as a heartbeat (Suricata never emits it); it counts only on
the mTLS channel with role "ids". The "ids" role is now included in sensor health, so
150 s silence marks evidence degraded (pauses automation), as for WAF and APP.

FW01 process check via serial console:
  pgrep -lx suricata  ->  51800 suricata ; pgrep -qx suricata -> PGREP_OK

Deploy: afw lab deploy --limit ctrl01 (deploy-ctrl01-ids-heartbeat.txt, failed=0);
watchdog installed by afw lab provision-geo (p5-ids-heartbeat-provision.txt).
